# Jahez for Owners — onboarding prototype

Interactive desktop prototype of the proposed login, account discovery, identity verification and onboarding flow for the Jahez for Owners app. All data is fictional and everything runs in the browser (no backend).

- `npm run dev` — local development
- `npm run build` — production build to `dist/`
- `npx playwright test` — end-to-end tests covering every scenario (uses local Chrome)

Test credentials are listed in the left panel of the prototype and in `src/data.ts`.
Pushing to `main` deploys to GitHub Pages.
